# Spiral Quiz 🌀

**螺旋式刷题助手** — 一个 AI 助手的 Skill，实现带"岔出追问"机制的沉浸式刷题体验。

## 这是什么

传统的 AI 刷题流程是线性的：

```
出题 → 答题 → 解析 → 下一题 → 答题 → 解析 ...
```

但真实的学习场景不是这样的。学生在看解析时经常会冒出新问题：

> "等等，为什么这个选项是对的？它的机制是什么？"
> "那这个病跟那个病怎么鉴别？"

Spiral Quiz 允许你**在解析中岔出去深入追问**，追问结束后**自然回到悬停的题目**，流程像螺旋一样递进：

```
出题① → 答题 → 解析全部选项 + 出题②（悬停）
                ↙                        ↘
        对解析中的知识点追问             直接回答悬停题
              ↓                             ↓
        回应追问 + 补充讲解            判断对错 + 解析 + 出题③
              ↓
        追问结束，自然回答悬停题②
```

全程不需要说"继续下一题"，直到你主动喊停。

## 适用场景

- 🩺 **医学生刷题** — 需要深度理解机制，而不仅仅是记答案
- 📚 **备考刷题** — 任何需要吃透知识点的学科
- 🧑‍🏫 **一对一辅导** — 模拟真人带教"讲着讲着岔出去再回来"

## Skill 功能

| 特性 | 说明 |
|------|------|
| 全选项解析 | 不管对错，每个选项都讲机制/病理/鉴别 |
| 自动衔接 | 解析完直接出下一题，不用额外指令 |
| 岔出追问 | 对解析内容深入提问，悬停题不丢失 |
| 盲区感知 | 记录易错点，后续题目自然覆盖薄弱环节 |
| 主动停止 | 用户说停就停，不做小总结 |

## 安装

1. 将本仓库下载到你的 AI 助手 skills 目录
2. 在设置中启用 spiral-quiz skill
3. 对助手说"来刷题"即可开始
