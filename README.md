# Spiral Quiz 🌀

**螺旋式刷题助手 v2.0** — 一个 AI 助手的 Skill，实现带薄弱点分析与难度适配的沉浸式刷题体验。

## 这是什么

传统的 AI 刷题工具是线性的：出题→答题→解析→下一题。

Spiral Quiz 不仅支持**岔出追问**（在解析中岔出去深入提问，追问结束后自然回到悬停题），更引入了**两阶段刷题系统**和**培养方案难度适配**：

```
📖 章节模式（复习阶段）
  选章节 → 刷题代替复习 → 实时薄弱点分析
  → 确诊机制（错2次才算弱）
  → 间隔强化回马枪（按遗忘曲线巩固）

📝 综合模式（冲刺阶段）
  综合选择题 / 模拟试卷 → 按培养方案自动匹配难度
```

## 核心特色

| 特性 | 说明 |
|------|------|
| 🧠 **薄弱点分析** | 实时识别未学过/混淆/遗忘三类薄弱点，确诊后才标记 |
| 🔁 **间隔强化** | 按遗忘曲线不定期回马枪，短期/中期/长期自然穿插 |
| 🎯 **培养方案适配** | 上传培养方案后，AI自动判断每门课难度（考研级/中等/基础） |
| 🔀 **岔出追问** | 全程可在解析中岔出去深入追问，悬停题不丢失 |
| 📖 **章节模式** | 刷题代替复习，基础→进阶→病例分析逐步升级 |
| 📝 **综合模式** | 复习完后做综合选择题或完整模拟试卷 |
| 🤖 **零指令衔接** | 解析完自动出下一题，不用额外指令 |

## 适用场景

- 🩺 **医学生备考** — 内外科、病理、生理等核心课程
- 📚 **任何需要深度理解的考试** — 按培养方案动态调整难度
- 🧑‍🏫 **一对一辅导** — 模拟真人带教"讲着讲着岔出去再回来"

## 安装

1. 将本仓库下载到你的 AI 助手 skills 目录
2. 在设置中启用 spiral-quiz skill
3. 对助手说"来刷题"即可开始
4. （可选）上传你的培养方案，AI自动适配各科难度
