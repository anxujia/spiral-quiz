# Spiral Quiz 🌀

**螺旋刷题 — AI 驱动的自适应刷题助手**

将教材/PPT/笔记扔给 AI，自动生成三级难度题目，按"答对升级、答错兜底"的螺旋逻辑逐题推进。

---

## 核心特色

| 特性 | 说明 |
|------|------|
| 📂 **扔资料自动读** | PDF / PPT / Word / 图片截图，扔进去就能出题 |
| 🔄 **螺旋出题** | C型答对升级（Level 1→2→3）+ A型答错兜底复现 |
| 🧠 **薄弱点管理** | 连续错3次确诊为薄弱点，按遗忘曲线周期性复现 |
| 🔀 **岔出追问** | 刷题中随时岔出去深入提问，回来接着做 |
| 📊 **进度持久化** | 多科目独立进度，随时切换，下次接着来 |
| 🎯 **难度适配** | 上传培养方案自动匹配各科难度，或手动指定 |
| 📝 **综合模考** | 复习完可生成综合选择题或模拟试卷 |

---

## 快速开始

### 安装

1. 将本仓库放入 AI 助手的 skills 目录
2. 在设置中启用 spiral-quiz
3. 把教材/PPT扔进对话，说"来刷题"

### 使用示例

```
用户：📎 精神病学PPT.pdf
用户："我要复习精神病学"
AI：已读取PPT，生成12个知识点，从Level 1开始——
    "抑郁症特征性睡眠障碍是？"

用户：选B，早醒
AI：✅ 正确！【选项解析】...
    【下一题】"抑郁症早醒 vs 焦虑入睡困难怎么鉴别？"

用户：等等，为什么焦虑是以入睡困难为主？
AI：因为焦虑是交感神经激活→警觉性↑→难以入睡...
    （刚才的题还在等你👇）
```
