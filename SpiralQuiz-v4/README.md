# Spiral Quiz 🌀

**螺旋刷题 — 自适应刷题助手，越刷越懂你**

把你的教材/PPT/笔记扔给 AI，自动生成三级难度题目，按"答对升级、答错兜底"的螺旋逻辑逐题推进。岔出追问不丢题，多科目进度独立保存。

---

## 核心特色

| 特性 | 说明 |
|------|------|
| 📂 **扔资料自动读** | PDF / PPT / Word / 图片，扔进去就能出题 |
| 🔄 **螺旋出题 C型** | 答对升级（Level 1→2→3），答错退回重练 |
| 🔀 **岔出追问** | 刷到一半随时问"为什么"，问完回来接着做 |
| 📊 **进度持久化** | 多科目独立进度，随时切换，下次接着来 |
| 💡 **错题信号** | 同知识点错 2 次轻提醒，不打断节奏，是否追问由你决定 |
| 📝 **综合模考** | 复习完可生成综合卷或模拟试卷 |

---

## 设计哲学

Spiral Quiz 的核心思路是**信号驱动，而非系统驱动**。

- 它不替你判断"你哪里弱"，而是在你出现重复错误时**轻轻点一下**
- 它不打断你的刷题节奏追着问"要不要出变式题"，而是等你主动追问
- 日常上下文占用 ~900 字，不常用的功能按需加载，Agent 跑得久也不退化

## 快速开始

### 安装

1. 将本仓库放入 AI 助手的 skills 目录
2. 在设置中启用 spiral-quiz
3. 把教材/PPT扔进对话，说"来刷题"

### 使用示例

```
你：📎 精神病学PPT.pdf
    "我要复习精神病学"

AI：已读取 PPT，生成 12 个知识点，从 Level 1 开始——
    "抑郁症特征性睡眠障碍是？"

你：选B，早醒

AI：✅ 正确！【选项解析】A.入睡困难—... B.早醒—抑郁症特征...
    【下一题】"老年抑郁早醒 vs 焦虑入睡困难怎么鉴别？"

你：等等，为什么焦虑以入睡困难为主？

AI：焦虑是交感神经激活→警觉性↑→难以入睡...
    （刚才的题还在等你👇）
```

## 项目结构

```
螺旋刷题/
├── SKILL.md                    ← 内核（常驻上下文，~900字）
│
├── rules/                      ← 扩展规则（按需加载）
│   ├── 综合模考.md              ← "来一套综合卷"时加载
│   └── 公开配置.md              ← 首次使用/环境说明时加载
│
├── 进度/                       ← 用户工作目录下自动生成
│   └── 掌握度.json              ← 含 _summary 摘要字段
│
└── 题库/                       ← 按科目/章节生成的题目
```

### 为什么拆成三部分？

| 模块 | 加载时机 | 大小 | 用途 |
|:--|:--|:--:|:--|
| **SKILL.md** | 永久 | ~900字 | 答题循环、螺旋出题、岔出追问、错题信号 |
| rules/综合模考.md | 按需 | ~200字 | 综合卷/模拟试卷 |
| rules/公开配置.md | 按需 | ~300字 | 引导/文件读取/培养方案/环境依赖 |

这种设计避免了"把所有规则塞进一个文件"导致的 Agent 退化问题——不常用的功能不占上下文，Agent 跑多久都不容易丢指令。
