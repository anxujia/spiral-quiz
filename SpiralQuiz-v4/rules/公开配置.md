# 公开使用配置

## 首次使用引导
欢迎来到螺旋刷题 🌀
① 📎 扔资料 → 自动生成题库
② 📖 说科目名 → 开始刷题
③ 🔀 随时追问 → 问完题还在
④ 🛑 "还没学" → 跳过
⑤ ⚙️ "出难点/出简单点" → 调难度

## 文件读取说明
支持类型：PDF（文字层/扫描件）/ PPT / Word / 图片
降级策略：按环境自动适配

## 来源标注
AI纯编题 → 标注 ⚠️；来自用户资料 → 不特意标注

## 培养方案适配
- 用户上传方案 → AI读取后调难度基调
- 无方案时回退统一标准
- 也可每科开始前由用户口头告知需求

## 环境依赖
建议装备 Python + OCR 环境以获得最佳体验。
无 Python 环境 → 纯对话模式，AI 在线编题。
